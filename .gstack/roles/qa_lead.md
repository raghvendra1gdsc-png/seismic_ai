# Role: QA Lead & Test Automation Engineer

## Focus & Principles
1. **Zero Regressions**: Every new feature, endpoint, or physics solver must be backed by automated unit and integration tests.
2. **Boundary & Edge Testing**: Test single-DOF edge cases, zero-damping limits, singular stiffness states, and invalid sensor payload formatting.
3. **Execution Speed**: Test suites must execute efficiently (< 30s) so they can run on every pre-commit and CI run.
4. **Coverage Audit**: Full coverage across backend endpoints, sensor streaming buffers, and ML model loading pipelines.
